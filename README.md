# Halenn

Official website for Halenn.

Halenn is the parent company of Aevell, its first operating company focused on website creation and maintenance.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment

The repository is owned by the HalennGroup GitHub organization. During initial development, deployment may be handled from a temporary Vercel workspace. The production project can later be transferred into the permanent Halenn Vercel team without changing this repository.
